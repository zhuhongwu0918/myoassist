# 反射控制（Reflex Control）

本页面提供反射控制工作流的总体概述，涵盖 2D 与 3D 两种设置。

## 概述

反射控制器是描述肌肉如何响应本体感觉刺激的模型。下图展示了一个完整的反射控制器：

```

    │   (mL)      │   │  │   反馈信号    │    │  肌肉刺激    │    │  兴奋动态    │───▶│  肌肉张力 │  │

    │   肌肉速度   │   │                             │                   │                          │
    │   (mV)      │───┼─────────────────────────────┘                   │                          │
```

## 反射控制器

MyoAssist 实现了一个反射控制器，基于多种本体感觉信号，通过非线性和组合反射生成肌肉刺激。反射参数在优化过程中被调优，以实现所需的运动行为。

### 基本结构

反射控制器将各种感觉信号映射为肌肉刺激。该模型模拟了参与肌肉激活的神经通路。

### 参数空间

在优化过程中调优的具体参数取决于模型类型。下表显示了 2D 与 3D 肌肉骨骼模型的参数分布：

| 反射参数 | 2D 模型（22 块肌肉） | 3D 模型（26 块肌肉） | 3D 模型（80 块肌肉） |
|-----------------------------------|-----------------------|-----------------------|-----------------------|
| 总参数（单侧反射） | 72 | 95 | 103 |
| 控制 2D 肌肉的参数 | 44 | — | — |
| 控制 3D 下肢肌肉的参数 | — | 52 | 60 |
| 腿内参数（2D 腿部 + 3D 腿部） | 22 | 26 | 26 |
| 躯干参数（斜方肌，[肌肉指数](../reinforcement-learning/04_network-index-handler_zh.md) 30） | 6 | 6 | 6 |
| 延迟肌肉（[肌肉指数](../reinforcement-learning/04_network-index-handler_zh.md) 14） | — | 11 | 11 |
| 对称设置（单侧反射） | 72 | 95 | 103 |
| 双侧（每条腿独立反射） | 144 | 190 | 206 |

### 2D 反射（我的腿）

对于 2D 肌肉骨骼模型，反射参数包括：

- **腿部肌肉**（22 块）：包括髋、膝、踝肌肉，通过跨肌肉群的反射进行控制
- **躯干肌肉**（6 块）：控制躯干姿势的肌肉，由躯干反射控制

### 3D 反射

对于 3D 肌肉骨骼模型，反射参数空间更大，并包含额外的肌肉群：

- **3D 下肢肌肉**：包括额外的髋、膝、踝肌肉
- **躯干肌肉**：与 2D 相同的躯干反射设置
- **延迟肌肉**：延迟肌肉反射

## 权重与参数

控制器中的每个反射参数都会乘以一个权重（增益）系数，该系数在优化过程中被调优。

### 参数生成

参数在优化过程中生成。`myoassist_utils/params` 模块生成了用于加载和生成参数数据的反射控制器骨架结构，并记录了肌群。你可以：

1. **按原样使用默认参数**：使用预优化控制器
2. **生成新参数**：在优化运行中生成新参数
3. **使用延迟肌肉**：使用 `--delayed` 标志运行仿真或优化

## 优化过程

在优化过程中：

1. **初始化**：创建一个包含控制参数的初始种群
2. **仿真**：每个候选解在 MuJoCo 仿真器中运行
3. **评估**：根据代价函数对性能进行评估
4. **更新**：CMA-ES 算法根据评估结果更新控制参数
5. **重复**：重复直到达到最大迭代次数或收敛

## 控制器模式

控制器支持多种模式，通过 `--reflex_mode` 标志指定：

| 模式 | 描述 |
|------|-------------|
| `uni` | 对称：一个反射块驱动两条腿 |
| `bilat` | 双侧：每条腿拥有独立的反射参数块 |
| `amp` | 截肢者：类似双侧模式，但用于截肢设备 |
| `ind` | 映射为对称，与 `uni` 相同 |

参见[运行优化](Running_Optimizations_zh.md)以了解详细说明。

## 关键脚本

- `run_ctrl_minimal.py` — 快速测试脚本，使用随机参数运行 5 秒仿真
- `run_ctrl.py` — 主要仿真脚本，支持视频生成和参数加载
- `run_optim.py` — 使用 CMA-ES 进行控制器参数优化

## 快速入门示例

要使用优化后的反射控制器：

```bash
# 使用预优化参数运行 30 秒仿真
python run_ctrl.py --mode exo \
    --param_path results/preoptimized/myolegs22_ReflexUni_MyoExo_KFoot_Marquardt.txt
```

该命令：
1. 加载预优化参数
2. 运行 30 秒仿真
3. 显示包括步态指标的仿真结果

## 延迟肌肉

延迟肌肉是反射控制的一个特殊功能。要使用延迟肌肉，使用 `--delayed` 标志：

```bash
python run_optim.py tutorial --delayed
```
